## 눈으로 본 공통점
- 영상 편집 도구 7곳 중 6곳이 **밝은 바탕**이다(OpusClip 만 검정).
- 첫 화면은 "가운데 한두 줄 제목 → 단추 2개 → 바로 아래 제품 화면"이다. 제목은 48~80px, 자간을 좁힌다.
- **첫 화면에서 바로 써 보게 하는 곳이 늘었다**: Captions 는 영상 올리는 상자, OpusClip 은 링크·파일 넣는 칸이 첫 화면에 있다.
- 색은 흑백 바탕에 강조색 하나. 화려한 색은 사이트가 아니라 **예시 영상 속 자막**이 맡는다(ChatCut 의 빨간 글자, Submagic 의 전·후 세로 영상).
- 한국어 페이지(브루·캡컷·채널톡)는 Pretendard 또는 Inter, 제목 굵기 600~700.
- 아래로는 "쓰는 곳 로고·사용자 수 → 기능 설명(그림과 함께) → 쓰임새 탭(크리에이터·마케팅·기업) → 요금 → 자주 묻는 질문" 순서가 많다.
