# 첫 화면(소개 페이지) 계획 — 2026-11-14 만듦

사용자가 방향(vigloostudio.com/ko 처럼 인터랙티브하고 역동적으로)과 요금·사업자 정보를 정해 줘서 같은 날 만들었다. 아래는 만들기 전의 계획이고, 실제 구성과 움직임 규칙은 `DESIGN.md` 「움직임」 절과 `src/site/` 가 주인이다.

「Website Design」 플러그인의 landing-page 절차: 사실을 모으고 → 구역마다 맡은 일을 정하고 → 사용자에게 보여 준 뒤 만든다.
지어내지 않는다: 고객 후기·로고·사용자 수·요금은 실제 값이 생기기 전에는 쓰지 않는다.

## 이 페이지가 이끄는 행동 하나
「영상 올려서 써 보기」 — 가입 없이 편집 화면으로 바로 간다.

## 구역과 맡은 일
1. **머리** — 로고 · 기능 · 요금 · 자주 묻는 질문 · 언어(한국어/日本語/English) · 로그인 · 주 단추.
2. **첫 화면** — 제목 「영상을 올리면 예능 자막이 붙습니다」, 설명 한 줄, 주 단추 하나. 옆에는 그림이 아니라 **실제로 움직이는 자막**(제품과 같은 코드가 그린다)과 디자인 4종 바꿔 보기.
3. **어떻게 되는지** — 올리기 → 말소리 받아 적기 → 디자인 고르기 → (내보내기). 실제 편집 화면으로 보여 준다.
4. **틀린 글자는 고치면 끝** — 글자를 고쳐도 말 시간이 그대로인 것을 보여 준다.
5. **자막 디자인** — 4종이 움직이는 견본. 일본·영어권 묶음은 생기면 더한다.
6. **요금** — 값이 정해지면 넣는다. 그 전에는 구역을 두지 않는다.
7. **자주 묻는 질문** — 내 영상은 어디로 가나 · 어떤 파일이 되나 · 얼마나 걸리나 · 만든 영상을 돈 버는 데 써도 되나.
8. **마지막 단추와 바닥** — 주 단추 한 번 더, 약관·개인정보·문의 링크, 사업자 정보.

「쓰는 곳 로고·후기」 구역은 두지 않는다(실제 값이 없다).

## 사용자가 줘야 하는 사실
- 요금제 값(무료 한도, 유료 가격)
- 사업자 정보(상호, 대표, 사업자등록번호, 주소, 통신판매업 신고번호)와 문의 받을 메일
- 도메인

## 만들기 전에 지킬 것
- 내보내기가 되기 전에는 "영상으로 저장"을 약속하는 문장을 쓰지 않는다.
- 다 만든 뒤 휴대폰(375) · 태블릿(768) · 데스크톱(1440)과 키보드만으로 확인한다.
