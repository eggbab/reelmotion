# ReelMotion — 서비스가 되려면 있어야 할 것 전부

사용자 지시(2026-11-14): "단순히 기능만 만들 게 아니라 하나의 서비스라면 마땅히 있어야 될 요소들을 전부 만들라. 웹사이트 등등 전부 다."
상태: ✔ 됨 · ◐ 일부 · ✗ 아직. 이 표가 할 일의 주인이다 — 끝낼 때마다 여기를 고친다.

## 1. 제품(편집기 `/app`)
| 항목 | 상태 | 비고 |

| 말로 고치는 대화창 | ✔ | 「말로 고치기」 탭: 우리 서버의 오픈 모델(Qwen3-4B, llama.cpp)이 그래픽 고치기를 만들고 편집기가 검사해 적용, 마지막 고치기 되돌리기. 세 언어. 실제 모델 시험 8/8 |

| 휴대폰에서 쓰기 | ◐ | 휴대폰 배치(미리보기를 위에 붙여 두고 바로 아래 타임라인, 그 아래 판), 손가락 크기(누르는 곳 40px 이상), 손짓(눌러 고른 뒤 끌기·끝을 끌어 길이·세로로 밀면 화면이 밀림·눈금과 막대로 위치), 긴 영상의 가로 밀기와 확대·축소, 세로 영상 비율, 내보내기까지 크롬의 휴대폰 흉내(터치 입력)로 확인(2026-11-15, 34개). **실제 아이폰·안드로이드 기기에서는 아직 못 해 봤다**(메모리·사파리의 내보내기) |
