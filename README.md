# ReelMotion

말하는 영상에 모션그래픽(제목·이름표·숫자·차트·목록·인용·자막)을 말에 맞춰 자동으로 얹는 웹 서비스.
방향·현재 상태·다음 할 일은 `AGENTS.md`, 디자인 규칙은 `DESIGN.md`, 서비스 전체 목록은 `docs/service-scope.md`.

```bash
npm install
npm run dev
```

- `/` 소개 페이지 · `/app` 편집기 · `/lab.html` 그래픽 견본(개발용)
- 검사: `npm run typecheck` · `npm run lint` · `npm test` · `npm run build`
